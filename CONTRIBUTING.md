# Contribuir a este repositorio

Este repositorio está diseñado exclusivamente para evaluar habilidades técnicas de candidatos a posiciones Android en The Empire.

Por favor, no envíes cambios a `main`.

Para completar el reto:

1. Haz un fork de este repositorio.
2. Crea una nueva rama: `git checkout -b nombre-apellido`
3. Agrega tu solución.
4. Crea un Pull Request hacia `main` desde tu fork.
5. Asegúrate de seguir el formato indicado en el archivo `PULL_REQUEST_TEMPLATE.md`.

Gracias por tu interés en trabajar con nosotros.
